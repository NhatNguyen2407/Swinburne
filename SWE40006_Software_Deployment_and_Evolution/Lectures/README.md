# Lecture materials

Store lecture slides and handouts here, grouped by teaching week.

## Suggested structure

```text
Lectures/
├── Week 01/
├── Week 02/
├── Week 03/
└── Week 04/
```

Use the original filenames from the learning materials where possible. Add later weeks as they become available.

> Materials are not included by this README alone; add the corresponding PDF files to each week folder.
