# SWE40006 – HelloWiX Deployment Project

This directory contains the source code and deployment configuration for **SWE40006 Software Deployment and Evolution – Task 1**.

## Project overview

HelloWiX is a Windows Forms desktop application developed to demonstrate application deployment using WiX/MSI and MSIX packaging.

### Project structure

- **HelloWiX** – .NET 8 Windows Forms desktop application.
- **HelloWiX.Installer/HelloWiX.Core** – .NET Standard 2.1 class library used as the application's separate dependency.
- **HelloWiX.Installer/HelloWiX.Installer** – WiX Toolset 4.0.5 project used to create the MSI installer.
- **HelloWiX.Package** – Windows Application Packaging Project used to create the MSIX package.

## Dependency deployment

The application calls `GreetingService.GetMessage()` from `HelloWiX.Core.dll`.

The final MSI was configured to deploy:

- `HelloWiX.exe`
- `HelloWiX.dll`
- `HelloWiX.Core.dll`
- `HelloWiX.deps.json`
- `HelloWiX.runtimeconfig.json`

The installed application was verified by launching it from the installed location and displaying the greeting generated by the separate dependency DLL.

## Deployment process

1. Develop and build the Windows Forms application.
2. Build the separate `HelloWiX.Core` dependency.
3. Configure WiX components for the executable, application DLL, dependency DLL, and .NET deployment metadata.
4. Build and install the MSI.
5. Verify the installed application and dependency.
6. Package the desktop application as MSIX.
7. Generate the Store upload package.
8. Upload the package to Microsoft Partner Center.
9. Configure the Store listing and submit the product for certification.

## Error investigation

The deployment process included investigation and resolution of:

- WiX SDK/CLI version mismatch.
- WiX package configuration errors.
- Missing UpgradeCode.
- WiX component GUID/versioned-file configuration.
- Missing .NET deployment metadata in the MSI.
- MSIX packaging prerequisites and platform configuration.
- Windows Developer Mode requirement for local package deployment.
- Microsoft Store account and submission requirements.

The assessment report documents the observed errors, causes, resolutions, and verification screenshots.
