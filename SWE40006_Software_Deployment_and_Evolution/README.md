# SWE40006 – HelloWiX Deployment Project

This directory contains the source code and deployment configuration for **SWE40006 Software Deployment and Evolution – Task 1**.

## Project overview

HelloWiX is a Windows Forms desktop application developed to demonstrate application deployment using WiX/MSI and MSIX packaging.

The solution contains:

- **HelloWiX** – Windows Forms desktop application targeting .NET 8.
- **HelloWiX.Core** – separate .NET Standard 2.1 class library used as an application dependency.
- **HelloWiX.Installer** – WiX Toolset 4.0.5 project used to create the MSI installer.
- **HelloWiX.Package** – Windows Application Packaging Project used to create the MSIX package for Store deployment.

## Dependency deployment

The desktop application uses the separate `HelloWiX.Core.dll` library. The final MSI deployment includes the application executable, application DLL, dependency DLL, and the .NET deployment metadata files required for framework-dependent execution:

- `HelloWiX.exe`
- `HelloWiX.dll`
- `HelloWiX.Core.dll`
- `HelloWiX.deps.json`
- `HelloWiX.runtimeconfig.json`

The installed application was verified by running it from the installed location and displaying the message generated by `HelloWiX.Core`.

## Deployment technologies

- Visual Studio
- .NET 8 Windows Forms
- WiX Toolset 4.0.5
- MSI
- MSIX
- Microsoft Partner Center / Microsoft Store

## Deployment process

1. Develop and build the Windows Forms application.
2. Build the separate `HelloWiX.Core` dependency.
3. Configure the WiX installer components.
4. Build the MSI package.
5. Install and verify the application and dependency files.
6. Package the desktop application as MSIX.
7. Generate the Store upload package.
8. Upload the package to Microsoft Partner Center.
9. Configure the Store listing and submit the product for certification.

## Error investigation

During development and deployment, several build and packaging issues were investigated and resolved, including WiX SDK version compatibility, WiX package configuration, component configuration, missing .NET deployment metadata, MSIX packaging prerequisites, Windows Developer Mode, and Microsoft Store submission requirements.

The report for the task documents these issues, their causes, resolutions, and verification evidence.
