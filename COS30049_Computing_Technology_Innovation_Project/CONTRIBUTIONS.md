- **Shared development:** Later changes by teammates also appear in some frontend files. The log demonstrates authored changes, not sole ownership of the final files.
- **Frontend API integration:** React's `ThreatScanner.jsx` posts to `http://localhost:8000/api/scan-text` using Axios and renders the returned result through `ScanningResult.jsx`. This does **not** establish ownership of the backend implementation or ML models.
- **Dashboard:** KPI figures and two Chart.js data series are hard-coded in the reviewed code. They are demonstration values, **not validated telemetry or real-time model metrics**.
- **Merge and artifact commits:** Two merges and a coursework-artifact reorganization are included in the 19-commit count; they should not be advertised as standalone product features.
- **Backend cache files:** The final authored commit tracks generated `__pycache__` files. These are not evidence of meaningful backend engineering.
- **Pull requests:** PR count and review participation cannot be verified from a Git Bundle alone.
- **No deployment claim:** No functional end-to-end runtime, production deployment, uptime, user adoption, or model-accuracy claim has been independently established.
