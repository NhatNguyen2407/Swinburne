## Project overview

**SigmaSecurity** is a group-built prototype exploring machine-learning-assisted spam and malware detection. The application combines a React web interface with a Python/FastAPI service and machine-learning work developed across the team. The active browser workflow submits text to a local spam-detection API and displays its returned classification details.

The interface includes a home/scan experience, an analytics dashboard, and an About page. Dashboard charts and KPIs in the reviewed source use **sample/hard-coded values**, not live telemetry; they should be presented as a UI/data-visualization prototype.
