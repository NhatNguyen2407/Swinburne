## Portfolio version

As part of a four-member university group project, I focused on frontend development and UX/UI for SigmaSecurity, a prototype combining a React web application with machine-learning-assisted spam and malware classification. I developed the original frontend structure and core interface components, implemented navigation across Home, Dashboard, and About screens, connected the text scanner to a backend API, and created the interface for displaying analysis results. I also built dashboard charts using demonstration data and iterated on component styling, error handling, and usability.

## Suggested interview narrative

The key challenge was turning a team ML prototype into an understandable end-user experience. I was responsible for the React UI: composing the page structure, providing a clear input-and-result flow, integrating the text scanner with the team's API, and prototyping visual feedback through the dashboard. The backend ML models were implemented by other contributors; I focused on their frontend presentation and integration.
