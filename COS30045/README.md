## Areas of work

### Labs
Weekly practical exercises covering data import, cleaning, transformation, aggregation, and visualisation with KNIME Analytics Platform.

### Assignments
Assessment-specific workflows, datasets, outputs, and supporting documentation. Each assessment should have its own README describing its purpose, process, files, and any limitations.

### Project
Project planning and development materials, including data exploration, visualisation design, implementation, demonstration, and reflection.

## Tools

- **KNIME Analytics Platform** — data preparation, transformation, and visualisation workflows
- **CSV** — tabular data and exported results
- **GitHub** — version control and documentation

## Working with KNIME workflows

1. Download or clone this repository.
2. Open KNIME Analytics Platform.
3. Import the relevant `.knwf` workflow using KNIME's workflow import option.
4. Check the workflow's file paths and update them if your local folder differs.
5. Execute the workflow from the source-data nodes, then inspect the output tables and charts.

A workflow may depend on a dataset being available at a particular path. Always verify file locations after importing it on another computer.

## Data and academic integrity

Course datasets, teaching materials, and assessment artefacts are included only for study and demonstration purposes. Check course rules and dataset licences before redistributing them publicly. Do not treat example values or interpretations as verified results unless they match the output produced by the workflow.

Any use of generative AI should be declared accurately and in accordance with the unit's assessment instructions.
