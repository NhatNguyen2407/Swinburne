02 / What D3 does

From a table to SVG

The CSV is loaded with d3.csv(), with the count converted into a number. D3 sorts the records, maps counts with scaleLinear(), and positions each brand using scaleBand(). A group holds the bar, brand name, and numeric label together.

This also makes it straightforward to display the full data or focus on the ten brands with the highest counts without manually drawing new rectangles.
